# datest

This repository provides a WordPress plugin that automatically generates and publishes posts using OpenRouter free models and Pixabay images.

## Plugin

**OpenRouter Auto Publisher**

- Generates article content using OpenRouter API.
- Fetches a relevant royalty-free image from Pixabay.
- Adds basic SEO meta tags to the published post.

## Usage

1. Copy the `openrouter-auto-publisher` directory to your WordPress site's `wp-content/plugins/` directory.
2. Activate **OpenRouter Auto Publisher** from the WordPress admin panel.
3. Configure your OpenRouter and Pixabay API keys under *API Settings*.
4. Use the *Generate Post* page to enter a topic and publish a complete article automatically.
